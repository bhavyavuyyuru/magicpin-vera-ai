# Magicpin AI Challenge Submission

## Team
- Name: Solo Developer
- Approach: Rule-based message composition using trigger types and context data.

## Implementation
- `bot.py`: Contains the `compose` function that generates messages based on trigger kind, using templates tailored to each type.
- `submission.jsonl`: 30 test messages generated by running the compose function on the test pairs.

## Tradeoffs
- Used simple string formatting instead of LLM for determinism and speed.
- Focused on specificity by including verifiable facts from contexts (e.g., dates, metrics).
- Generic fallback for unhandled trigger kinds to ensure all cases are covered.
- No multi-turn handling implemented, as it's optional.
